# Develop an idea

Read `docs/dev-flow/flow.md` and `docs/dev-flow/stage-idea.md`. Do the steps of `stage-idea.md`.

- Take the idea description from the arguments. If there are no arguments, ask the operator.
- Read `docs/ideas/` and `docs/specs/` for related work before the interview.
- The issue of this stage is for the idea only. The design stage creates a new issue.
