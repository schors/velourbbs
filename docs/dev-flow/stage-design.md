# Stage: Design

1. Create the issue with `/ticket new dev`.
2. Read the idea from `docs/ideas/`.
3. Interview the operator about open points.
4. Select the solutions. Write the design and the specifications to `docs/specs/`.
5. Run reviewers as subagents. Go back to step 3 until the operator confirms.
6. Commit.

Result: an issue with a design and specifications, ready for decomposition.
