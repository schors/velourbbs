# Įdiegimo vadovas

Šis vadovas moko įdiegti, patikrinti ir paleisti Velour BBS Linux serveryje.
Jis skirtas sistemos operatoriui.
Tau reikia Linux serverio su systemd, root teisių, teksto redaktoriaus ir telnet kliento.

Kiekvienas skyrius baigiasi rezultato patikra.
Skyrius nurodo specifikacijas, kuriose yra jo visos taisyklės.
Ekranus rašyti moko [BBT vadovas](../bbt/README.md).
