# Задача 1. Каталог BBS

1. Создай каталог, например `mybbs`. Создай в нём каталог `screens`.
2. Создай пустой файл `bbs.toml`.
3. Создай `screens/main.bbt` с таким текстом:

```
+++
[[item]]
key = "G"
do = "logoff"
+++
Привет! Это моя BBS.

G  до свидания
```

Строки между двумя строками `+++` — это «front matter». Он задаёт меню экрана.
Здесь в меню один пункт: клавиша `G` завершает сеанс (`logoff`).
У экрана должен быть хотя бы один пункт. Только у экрана `goodbye` нет пунктов (задача 4).
Остальные строки — это «тело»: текст экрана.
BBS показывает экран `main` первым.

## Проверь файлы

Выполни:

```
velourbbs check
```

Если файлы верны, команда ничего не выводит.
Иначе она выводит по строке на каждую ошибку или предупреждение:

```
screens/_x.bbt:1:1: warning: no screen uses this file
screens/main.bbt:2:1: item "G": do: unknown action "logof"
```

Строка содержит файл, номер строки, номер столбца и сообщение.
Ошибка в пункте указывает строку 2: первую строку front matter.
У предупреждения перед сообщением стоит `warning:`. Предупреждение не останавливает BBS. Ошибка останавливает.
Полные правила: [screen-render](../../../specs/screen-render.md), раздел 3.1.

## Посмотри на экран

Выполни:

```
velourbbs preview main
```

Команда выводит «cell dump» экрана для терминала 80 столбцов на 24 строки:

```
page 1 80x24 fill none
|Привет! Это моя BBS.                                                            |
|                                                                                |
|G  до свидания                                                                  |
styles
1: 1-80 7/0
2: 1-80 7/0
3: 1-80 7/0
```

- Первая строка содержит страницу, размер терминала и заполнение строк под экраном.
- Каждая строка экрана стоит между двумя `|`.
- Каждая строка после `styles` содержит номер строки и «отрезки стилей» этой строки.
  Отрезок содержит первый столбец, последний столбец и стиль. `7/0` — светло-серый на чёрном.

Для других размеров используй `--size`, например `velourbbs preview main --size 132x43`.
Полные правила: [screen-render](../../../specs/screen-render.md), разделы 3.2 и 3.3.

## Посмотри на экран в telnet-клиенте

1. Выполни `velourbbs serve`. Сервер слушает порт 2323.
2. Подключи telnet-клиент к `localhost`, порт 2323. Используй PuTTY или Tera Term:
   они показывают UTF-8 и 256 цветов. SyncTERM и NetRunner не показывают UTF-8.
   В PuTTY выбери тип соединения «Telnet».
   Установи «Close window on exit» в «Never»: иначе PuTTY закрывает окно в конце сеанса.
3. Нажми `G`, чтобы завершить сеанс.

Сервер читает файлы только при запуске. После каждого изменения файла
останови сервер клавишами Ctrl+C и запусти снова.
Полные правила: [telnet-term](../../../specs/telnet-term.md), разделы 3 и 6.

## Результат

- `velourbbs check` ничего не выводит.
- Telnet-клиент показывает две строки текста. `G` завершает сеанс.
