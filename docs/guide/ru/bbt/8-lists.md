# Задача 8. Списки

В этой задаче ты добавляешь в «Лампу» журнал смотрителя. Экран `log` показывает список заметок
из каталога `content/log/`. Строку для каждой заметки писать не нужно:
BBS читает каталог и сама делает строки. Стрелки выбирают заметку,
а Enter открывает её в читалке из задачи 7.

## Заметки

Создай каталог `content/log/` и семь заметок в нём:
`1-first-night.md`, `2-rain.md`, `3-north.md`, `4-wick.md`, `5-winter.md`,
`6-moths.md` и `7-tea.md`. Каждая заметка — файл Markdown с заголовком уровня 1.
Заголовок — название заметки.

`examples/lamp/ru/content/log/1-first-night.md`:
```
# Первая ночь

Я зажёг лампу в девять. Модем пропел свою короткую песню,
и первый гость пришёл в четверть одиннадцатого.

Мы поговорили о погоде и о старых терминалах.
В полночь я записал эту заметку и чуть убавил фитиль.
```

Остальные заметки устроены так же. Их тексты лежат в `examples/lamp/ru/content/log/`.
Заметка `5-winter.md` длиннее: её время чтения — 2 минуты.

## Экран-список

«Экран-список» — экран с ключом `data`. Он показывает строки «поставщика» по страницам.

| Ключ | Значение |
|---|---|
| `data` | Поставщик: `from` и `args`. |
| `rows` | Наибольшее число строк на странице, от 1 до 100. В экране-списке он обязателен. |

Поставщик `files` даёт файлы содержимого одного каталога:

```
data = { from = "files", args = { dir = "log" } }
rows = 5
```

- `dir` — путь в `content/`, как ключ `file` файлового экрана (задача 7).
  Если каталога нет, это ошибка.
- Строка — каждый файл каталога. BBS не заходит в подкаталоги.
  Имя, которое не годится для части пути, например `.keep`, BBS пропускает.
- Порядок: сначала `README.md`, потом «естественный порядок». Цифры в нём сравниваются как числа:
  `2-rain.md` идёт раньше `10-art.md`.
- Каждый файл — файл содержимого: его ошибки — ошибки `velourbbs check` (задача 7).
- BBS читает строки при старте. Перезапусти `velourbbs serve`, когда добавишь заметку.
- У экрана-списка не может быть ключа `file`.

Полные правила: [list-view](../../../specs/list-view.md), разделы 3 и 4.

## Строка списка

«Строка списка» — строка исходника, которая начинается с `{#each}` и кончается `{/each}`.
Текст между ними — «текст строки»: BBS показывает его один раз для каждой строки страницы.

```
{#each}         {!dim}{row.num}{!}   {row.title                             }{!dim}{row.minutes} мин{/each}
```

- Строка списка даёт ровно одну страницу строк: по одной на каждую строку страницы,
  потом пустые строки. На странице `rows` строк, а в маленьком терминале меньше (раздел «Страницы»). Поэтому строки под списком стоят на месте на каждой странице.
- Строка не переносится. BBS обрезает её по ширине экрана.
- В тексте строки могут быть поля, токены стиля и блоки `{#if}`.
  Блоки должны закрываться в той же строке. Включения и вставки арта в нём не работают.
- Каждая строка начинается со стиля, который был перед строкой списка.
  После строки списка стиль тот же, что был перед ней.
- Строка списка может стоять в блоке и во фрагменте. Список у экрана один:
  каждая строка списка показывает ту же страницу.

Поля строки и списка:

| Поле | Значение |
|---|---|
| `row.num` | Номер строки в списке, с 1. |
| `row.title` | Название файла, как `file.title` (задача 7). |
| `row.minutes` | Время чтения файла. |
| `row.path` | Путь файла в `content/`, например `log/2-rain.md`. |
| `row.selected` | Истинно на выбранной строке (раздел «Выбор»). Только в условии. |
| `list.page` | Номер текущей страницы, с 1. |
| `list.pages` | Число страниц. У пустого списка одна страница. |
| `list.last` | Истинно на последней странице. Только в условии. |
| `list.empty` | Истинно, когда в списке нет строк. Только в условии. |

- Поле `row.*` работает только в тексте строки и в значении `select`.
- Поле `list.*` работает только в экране-списке: в его тексте, фрагментах, арте и `when`.

Полные правила: [list-view](../../../specs/list-view.md), разделы 5 и 6.

## Выбор

Ключ `select` даёт экрану-списку «курсор»: одну выбранную строку страницы.
Enter выполняет действие `select` с выбранной строкой:

```
select = { do = "gosub reader", args = { file = "{row.path}" } }
```

- `do` — действие, как `do` пункта меню (задача 4).
- Значение `args` — текст или ровно одно поле `{row.<field>}`.
  Enter кладёт в аргумент значение выбранной строки.
  Здесь `{row.path}` передаёт экрану `reader` из задачи 7 файл заметки.
- BBS загружает файл каждой строки для `reader` при старте.
  Ошибка в файле — ошибка `velourbbs check`.
- `Up` и `Down` двигают курсор. На последней строке страницы `Down` показывает следующую страницу.
  На первой строке страницы `Up` показывает предыдущую.
  На концах списка клавиши ничего не делают. Enter в пустом списке ничего не делает.
- В экране с `select` у пункта меню не может быть клавиши `UP`, `DOWN` или `ENTER`.
- Действие `page` ставит курсор на первую строку новой страницы.
  `back` из `reader` показывает ту же страницу и ту же строку.
- Когда курсор двигается по той же странице, BBS отправляет только две изменённые строки.

`row.selected` истинно на выбранной строке. Текст строки `log` показывает знак `☼`
в стиле `orn` перед номером выбранной строки, а её название — в стиле `title`:

```
{#each}{#if row.selected}       {!orn}☼{!} {#else}         {/if}{!dim}{row.num}{!}   {#if row.selected}{!title}{/if}{row.title                             }{!dim}{row.minutes} мин{/each}
```

Обе ветки первого блока дают 9 клеток, поэтому номер остаётся в столбце 10.

Полные правила: [list-view](../../../specs/list-view.md), раздел 8,
и [menu-nav](../../../specs/menu-nav.md), разделы 3.3 и 5.3.

## Экран `log`

`examples/lamp/ru/screens/log.bbt`:
```
+++
data = { from = "files", args = { dir = "log" } }
rows = 5
select = { do = "gosub reader", args = { file = "{row.path}" } }
[[item]]
key = "SPACE"
do = "page next"
when = "not list.last"
[[item]]
key = "B"
do = "page prev"
when = "list.page > 1"
[[item]]
key = "ESC"
do = "back"
+++
{>_head}
       {!title}Журнал смотрителя{!}
       {!dim}заметки о ночах  ∙  стр. {list.page}/{list.pages}{!}

{#each}{#if row.selected}       {!orn}☼{!} {#else}         {/if}{!dim}{row.num}{!}   {#if row.selected}{!title}{/if}{row.title                             }{!dim}{row.minutes} мин{/each}







  {!line}────────────────────────────────────────────────────────────────────────────{!}

    {!key}↑↓{!}  {!dim}выбор{!}   {!key}Enter{!}  {!dim}читать{!}   {#if item.SPACE}{!key}Space{!}  {!dim}дальше{!}   {/if}{#if item.B}{!key}B{!}  {!dim}пред.{!}   {/if}{!key}Esc{!}  {!dim}назад{!}
```

Экран:

```text

  ────────────────────────────────────────────────────────────────────────────

       Лампа  ☼ BBS при свете лампы

       Журнал смотрителя
       заметки о ночах  ∙  стр. 1/2

       ☼ 1   Первая ночь                             1 мин
         2   Дождь по крыше                          1 мин
         3   Гость с севера                          1 мин
         4   Новый фитиль                            1 мин
         5   Долгий зимний вечер                     2 мин







  ────────────────────────────────────────────────────────────────────────────

    ↑↓  выбор   Enter  читать   Space  дальше   Esc  назад
```

- Строки списка — строки 9–13. Пустые строки под строкой списка
  оставляют нижнюю линию в строке 21.
- `{row.title                             }` — поле фиксированной ширины в 40 клеток (задача 5).
  Поэтому время чтения начинается со столбца 54, как пояснения пунктов меню.

## Страницы

Действия `page` из задачи 7 работают и в экране-списке.
`when` и `{#if item.<KEY>}` используют `list.last` и `list.page`, как `file.last` и `file.page`.

В списке 7 строк, на странице 5 строк. Поэтому на странице 2 две заметки и три пустые строки.

Если экран не помещается в терминал, строк на странице меньше.
BBS рисует страницу 1 и считает её строки. Если экран длиннее терминала
на `n` строк, на странице `rows - n` строк, но не меньше 1. При 80x20 в экране `log` 23 строки,
поэтому на странице 2 строки, а в списке 4 страницы:

```text
       Журнал смотрителя
       заметки о ночах  ∙  стр. 1/4

       ☼ 1   Первая ночь                             1 мин
         2   Дождь по крыше                          1 мин
```

У экрана-списка нет строки More.

У пустого списка одна страница с пустыми строками. Покажи для него текст через `list.empty`:

```
{#if list.empty}       {!dim}Заметок пока нет.{!}{/if}
```

Полные правила: [list-view](../../../specs/list-view.md), раздел 7,
и [menu-nav](../../../specs/menu-nav.md), раздел 5.3.

Пункт `L` ведёт на экран `log`. Его строка стоит между строками `R` и `T`.
Убери одну пустую строку над строкой `A` и одну под строкой `G`.

## Список с аргументом

Значение `args` в `data` может быть одним аргументом экрана: `{arg.<name>}`.
Так один экран показывает разные каталоги:

```
data = { from = "files", args = { dir = "{arg.dir}" } }
```

```
[[item]]
key = "1"
do = "gosub notes"
args = { dir = "log" }
```

- BBS читает строки каждого значения `dir`, которое даёт `goto` или `gosub`.
- `velourbbs preview notes --set arg.dir=log` показывает строки этого значения.

## Проверь страницы

```
velourbbs preview log
```

Команда выводит обе страницы списка, одну за другой.
`--size 80x20` выводит четыре страницы маленького терминала.

`--keys` двигает курсор, открывает заметку и листает страницы:

```
velourbbs preview main --keys L,DOWN,ENTER,ESC,SPACE,B,ESC
```

Движение курсора выводит всю страницу, с курсором на новой строке.

## Результат

- `velourbbs check` ничего не выводит.
- `velourbbs preview log` выводит две страницы. Страница 1 — экран выше.
- В telnet-клиенте `L` показывает журнал. `Up` и `Down` двигают курсор,
  Enter открывает заметку, `Esc` возвращает на ту же строку.
  `Space` и `B` листают страницы, `Esc` возвращает в меню.
