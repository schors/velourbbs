# Задача 5. Поля и условия

В этой задаче ты пишешь экран `term`. Он показывает, что BBS знает о терминале пользователя.

## Поля

«Поле» — это токен, который BBS заменяет значением:

```
       {!dim}Размер{!}   {term.cols}×{term.rows}
```

На терминале 80 столбцов на 24 строки эта строка показывает `Размер   80×24`.

| Поле | Значение |
|---|---|
| `term.cols` | Число столбцов терминала, от 20 до 255. |
| `term.rows` | Число строк терминала, от 10 до 100. |
| `term.colors` | Глубина цвета: `16`, `256` или `16777216` (задача 6). |
| `term.type` | Тип терминала, который передаёт клиент, в нижнем регистре. Без типа — `ansi`. |
| `term.charset` | Всегда `utf-8`. |
| `term.name` | Имя и версия, которые сообщает терминал, например `XTerm(412)`. Может быть пустым. Используй его только для показа. |
| `term.images` | `sixel`, когда терминал сообщает о графике sixel. Иначе пусто. Некоторые терминалы сообщают о ней, но не показывают sixel. |
| `term.ambiguous` | `2`, когда терминал показывает символы East Asian Ambiguous, например кириллицу и `■`, в двух клетках. Иначе `1`. Раскладка не меняется, поэтому рамки и колонки ломаются. Используй его, чтобы показать пользователю, как выключить эту настройку. |
| `term.bg_color` | Цвет фона, который сообщает терминал, как `#rrggbb` в нижнем регистре. Пусто, когда терминал не сообщает его. |
| `term.fg_color` | Цвет текста, который сообщает терминал, как `#rrggbb` в нижнем регистре. Пусто, когда терминал не сообщает его. |
| `term.background` | `light`, когда `term.bg_color` — светлый цвет, например серый `#bcbcbc` или светлее. `dark` для тёмного цвета. Пусто, когда `term.bg_color` пустой. |

- Поле без пробелов в фигурных скобках берёт ширину своего значения.
- У поля с пробелами в фигурных скобках «фиксированная ширина»: ширина токена вместе со скобками.
  BBS дополняет короткое значение пробелами и обрезает конец длинного значения.
  Пробелы после имени выравнивают значение влево. Пробелы перед именем выравнивают его вправо.

```
[{term.type      }]
[{      term.type}]
```

Каждый токен шириной 17 клеток. BBS показывает:

```text
[xterm            ]
[            xterm]
```

- `{` начинает токен, когда за ней идёт латинская буква, пробел или знак пунктуации ASCII,
  кроме `{` и `}`. Знаки, кроме `#`, `/`, `!` и `>`, зарезервированы:
  их токен — ошибка. `{{` даёт простую `{`. Пример: `Напиши {{name} здесь.` показывает `Напиши {name} здесь.`

## Поля сессии и BBS

Другие поля показывают данные сессии и BBS:

```
{bbs.name} {bbs.version}  {bbs.time}
Твой адрес {session.ip}, на связи {session.online}
Сейчас на связи {bbs.sessions}, BBS работает {bbs.uptime}
```

| Поле | Значение |
|---|---|
| `session.ip` | Адрес пользователя. Пример: `203.0.113.7`. |
| `session.theme` | Выбор темы в сессии: `dark`, `light` или `auto` (задача 6). |
| `session.lang` | Язык сессии, например `en` (задача 7). |
| `session.online` | Время от подключения пользователя: `чч:мм:сс`, от 24 часов `<д>d чч:мм:сс`. |
| `bbs.name` | Ключ `name` таблицы `[bbs]` в `bbs.toml`. По умолчанию `Kind Brothers BBS`. |
| `bbs.version` | Версия `velourbbs`, например `v1.2.0`. Сборка не из тега релиза даёт `dev`. |
| `bbs.sessions` | Сколько пользователей на связи сейчас, вместе с этим пользователем. |
| `bbs.time` | Дата и время сервера, в зоне `[screen] zone`. |
| `bbs.uptime` | Время от запуска `velourbbs serve`, в форме `session.online`. |

- BBS берёт значения, когда показывает экран. Значение на экране не меняется
  до следующего экрана.
- `[screen] time` в `screens/screens.toml` задаёт форму `bbs.time` через опорное время Go
  `2006-01-02 15:04:05`. По умолчанию `"2006-01-02 15:04:05"`. Пример для `16.11.2026 15:04`:

```toml
[screen]
time = "02.01.2006 15:04"
```

- `[screen] zone` задаёт часовой пояс `bbs.time`: `"Local"`, `"UTC"` или имя зоны,
  например `"Europe/Berlin"`. По умолчанию `"Local"` - пояс сервера.
  `MST` в `time` показывает зону. Пример для `14:05 UTC`:

```toml
[screen]
time = "15:04 MST"
zone = "UTC"
```

- У `velourbbs preview` нет сессии. Он показывает `127.0.0.1`, `00:00:00`, `1` пользователя
  и время `2006-01-02 15:04:05` в зоне `[screen] zone`, для `"Local"` - в UTC. `--set` меняет значение, например
  `--set bbs.sessions=12`.

Полные правила: [session-fields](../../../specs/session-fields.md), разделы 2–4.

## Алиасы

`[fields]` в `screens/screens.toml` даёт полю короткое имя — «алиас»:

```toml
[fields]
w = "term.cols"
```

Тогда `{w}` показывает число столбцов терминала. Короткий алиас помогает в арте (задача 9).

Полные правила: [bbt-format](../../../specs/bbt-format.md), разделы 3.3 и 4,
и [screens-toml](../../../specs/screens-toml.md), раздел 3.3.

## Условия

```
{#if term.colors == 16777216}16 млн{#else}{term.colors}{/if}
```

Этот текст показывает `16 млн`, когда терминал показывает 16777216 цветов. Иначе он показывает число.

- `{#if <условие>}` показывает текст до `{#else}` или `{/if}`, когда условие истинно.
- `{#else}` показывает текст до `{/if}`, когда условие ложно. `{#else}` не обязателен.
- Блок может занимать несколько строк и содержать другие блоки.
  Каждому `{#if}` нужен свой `{/if}` в том же файле.
- Строка с `{#if}`, `{#else}` или `{/if}` не даёт строки экрана, когда на ней остались только пробелы.
- Операторы: `==`, `!=`, `<`, `<=`, `>` и `>=`.
  Числовое поле принимает число и любой оператор.
  Текстовое поле принимает текст в двойных кавычках и только `==` или `!=`: `term.type == "xterm"`.
- `and` и `or` соединяют условия. `and` связывает сильнее. Скобок нет.

Полные правила: [bbt-format](../../../specs/bbt-format.md), разделы 5 и 6.2.

## Пункты с условием

`when` даёт пункту условие. Когда условие ложно, пункт не работает.
`{#if item.<KEY>}` истинно, когда пункт `<KEY>` работает. Так текст пункта и его клавиша согласованы:

```
+++
[[item]]
key = "W"
do = "gosub wide"
when = "term.cols >= 132"
[[item]]
key = "G"
do = "logoff"
+++
{#if item.W}W  широкий экран{/if}
G  до свидания
```

На терминале шириной 132 столбца и больше экран показывает `W  широкий экран`, и `W` работает.
На более узком терминале эта строка не даёт строки экрана, и BBS игнорирует `W`.
`not item.W` истинно, когда пункт не работает.

Полные правила: [bbt-format](../../../specs/bbt-format.md), раздел 8.2.

## Список полей

`velourbbs fields` выводит поля твоей BBS. Часть вывода:

```
velourbbs fields
```

```text
term.type        string   -   -      xterm
term.cols        integer  3   -      80
term.colors      integer  8   -      256
term.background  string   5   -
session.lang     string   2   -      ru
bbs.name         string   -   -      Kind Brothers BBS
```

- Каждая строка даёт путь, тип, ширину, поставщика (задача 8) и пример значения.
- Ширина — самое большое число клеток значения. `-` значит, что у значения нет предела.
  Используй ширину для поля фиксированной ширины: `{term.cols}` нужно 3 клетки, `{term.background}` — 5.
- Пример значения — значение `velourbbs preview`.
- Сначала команда делает проверки `velourbbs check`. После ошибки она выводит только ошибки.

Полные правила: [screen-render](../../../specs/screen-render.md), раздел 3.4.

## Экран `term`

Создай `screens/term.bbt` с таким текстом:

`examples/lamp/ru/screens/term.bbt`:
```
+++
[[item]]
key = "ESC"
do = "back"
[[item]]
key = "ENTER"
do = "back"
+++
{>_head}
       {!dim}Размер{!}   {term.cols}×{term.rows}
       {!dim}Цветов{!}   {#if term.colors == 16777216}16 млн{#else}{term.colors}{/if}
       {!dim}Тип{!}      {term.type}

       Так тебя видит станция.










  {!line}────────────────────────────────────────────────────────────────────────────{!}

    {!key}Esc Enter{!}  {!dim}назад{!}
```

Экран для терминала 80 столбцов на 24 строки:

```text

  ────────────────────────────────────────────────────────────────────────────

       Лампа  ☼ BBS при свете лампы

       Размер   80×24
       Цветов   256
       Тип      xterm

       Так тебя видит станция.










  ────────────────────────────────────────────────────────────────────────────

    Esc Enter  назад
```

Подписи «Размер», «Цветов» и «Тип» серо-коричневые, в стиле `dim`. Значения кремовые, в стиле `normal`.

## Пункт `T` в `main`

Добавь пункт `T` во front matter файла `screens/main.bbt`, после пункта `A`:

```
[[item]]
key = "T"
do = "gosub term"
```

В теле добавь строку `T` между строками `A` и `G`.
Убери две пустые строки под строкой `G`: так «Свет горит до утра.» остаётся в строке 19.
Добавь `T` в строку клавиш:

```
         {!key}A{!}   О станции                               {!dim}кто мы{!}

         {!key}T{!}   Твой терминал                           {!dim}размер и цвета{!}

         {!key}G{!}   До свидания                             {!dim}лампа подождёт{!}
```

```
    {!key}A T G{!}  {!dim}выбор{!}
```

## Результат

- `velourbbs check` ничего не выводит.
- `velourbbs preview main --keys T` показывает экран `term`.
- `velourbbs preview term` выводит строки `Размер   80×24`, `Цветов   256` и `Тип      xterm`.
- `velourbbs preview term --set term.type=ansi` выводит `Цветов   16` и `Тип      ansi`.
- `velourbbs preview term --set term.colors=16777216` выводит `Цветов   16 млн`.
- В telnet-клиенте `T` показывает размер окна. Измени ширину окна,
  оставь не меньше 24 строк, нажми `Esc` и снова `T`: экран показывает новый размер.
  Если строк меньше, BBS показывает экран по страницам (задача 6), и клавиша только открывает следующую страницу.
