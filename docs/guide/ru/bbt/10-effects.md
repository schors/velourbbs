# Задача 10. Эффекты

«Эффект» меняет клетки экрана, пока экран ждёт клавишу.
В этой задаче ты добавляешь эффекты к лампе из задачи 9: свет лампы мерцает,
вокруг неё мигают звёзды, а рядом с клавишей горят два маленьких огонька.
Используй каталог `myart` из задачи 9.

## Таблица `[[effect]]`

Каждый эффект — это одна таблица `[[effect]]` во front matter:

```
[[effect]]
do = "twinkle"
at = [37, 3]
chars = "*+·"
```

- `do` называет эффект. Эта задача показывает `twinkle` и `candle`.
- `at` — это «место»: клетки, где действует эффект (ниже).
- У экрана не больше 16 эффектов. Эффекты действуют в порядке файла:
  эффект меняет клетки после эффектов выше него.
- Экраны `goodbye` и `shutdown` не ждут клавишу, поэтому эффектов у них быть не может.
- Эффекты не действуют на странице со строкой More и пока пользователь вводит строку (задача 8).
- Каждый раз, когда BBS показывает экран, эффекты начинаются заново.

Полные правила: [live-screen](../../../specs/live-screen.md), разделы 5 и 6.1.

## Место

У `at` одна из трёх форм:

| Форма | Пример | Клетки |
|---|---|---|
| Точка `[col, row]` | `[61, 3]` | Одна клетка. |
| Прямоугольник `[col, row, width, height]` | `[1, 1, 80, 6]` | Прямоугольник от точки: `width` столбцов вправо и `height` строк вниз. |
| Массив точек | `[[61, 3], [70, 5]]` | Каждая точка — отдельное место со своим временем. |

- С `in = "<name>.ans"` координаты считаются в арте: столбец 1 и строка 1 —
  первая клетка арта. Место движется вместе с артом. Если текст над артом переносится
  на большее число строк, эффект остаётся на тех же клетках арта.
- Без `in` координаты считаются на странице. Столбец 1 — левый край экрана,
  строка 1 — первая строка страницы. Текст с переносом сдвигает строки под ним, поэтому
  используй эту форму только для строк без переноса: заголовка, угла или строки клавиш.
- Отрицательная координата считается с конца: `-1` — последний столбец или последняя строка
  арта либо экрана и страницы. Пример: `[-1, -1]` — клетка в правом нижнем углу.
- Живое поле (задача 5) и широкий символ, например `語`, не входят в место.
  Эффект никогда их не меняет.
- Клетка, которую экран не показывает, не входит в место: например,
  клетка арта, обрезанная у края узкого терминала.

`velourbbs check` выводит ошибку, если экран не вставляет арт из `in`
или если клетка места лежит вне арта.

Полные правила: [live-screen](../../../specs/live-screen.md), раздел 6.2.

## Время

| Ключ | По умолчанию | Значение |
|---|---|---|
| `delay` | `0` | Секунды до первой смены: 0–3600. |
| `every` | Своё у каждого эффекта. | Секунды между двумя сменами: 0.05–3600. |
| `spread` | Половина `every`. | Случайная часть `every`: каждый промежуток равен `every` плюс-минус до `spread`. |

- Значение — число секунд, например `0.5`.
- С `spread = 0` каждая смена приходит ровно через `every` секунд после предыдущей.
- `every - spread` должно быть не меньше 0.05.
- Смены случайны. У каждой сессии свои случайные значения.

Полные правила: [live-screen](../../../specs/live-screen.md), раздел 6.3.

## Эффект `twinkle`

Звезда, которая видна всегда и меняет свой символ.

| Ключ | По умолчанию | Значение |
|---|---|---|
| `at` | Обязателен. | Точка, прямоугольник или массив точек. |
| `chars` | Обязателен. | 1–32 символа шириной в одну клетку, среди них не меньше 2 разных. |
| `colors` | Нет. | 1–16 цветов: стиль, например `"215"` или `"#ffcc00"`, или имя стиля темы. |
| `every` | `1` | |
| `share` | `0.1` | Доля звёзд прямоугольника, которые меняются за раз: больше 0, не больше 1. |

- Точка показывает звезду с самого начала: свой символ, если он есть в `chars`, иначе первый
  символ `chars`. При каждой смене звезда берёт другой символ из `chars`.
- В прямоугольнике звёзды — это клетки с символом из `chars`.
  При каждой смене доля `share` из них берёт другой символ из `chars`.
- С `colors` каждый новый символ берёт случайный цвет из `colors`.
  Иначе он сохраняет цвет клетки. Фон не меняется.

## Эффект `candle`

Огонёк, который дрожит.

| Ключ | По умолчанию | Значение |
|---|---|---|
| `at` | Обязателен. | Точка, прямоугольник или массив точек. |
| `chars` | Обязателен. | 1–32 символа шириной в одну клетку. |
| `colors` | Обязателен. | 1–16 цветов, как у `twinkle`. |
| `every` | `0.2` | |
| `share` | `0.3` | Доля клеток прямоугольника, которые меняются за раз. |

- С самого начала каждая клетка места показывает первый символ `chars`
  в первом цвете `colors`.
- При каждой смене точка берёт случайный символ из `chars` и случайный цвет из `colors`.
  В прямоугольнике так делает доля `share` клеток.

Полные правила: [live-screen](../../../specs/live-screen.md), разделы 6.4 и 6.6.

## Файл

Измени `screens/main.bbt`:

`examples/art/screens/main.bbt`:
```
+++
width = [40, 40]
fill = "spaces"
[[effect]]
do = "twinkle"
in = "lamp.ans"
at = [8, 5, 26, 3]
chars = "░▒"
share = 0.2
[[effect]]
do = "twinkle"
in = "lamp.ans"
at = [[4, 2], [37, 3], [2, 9], [39, 10]]
chars = "·+*"
colors = ["223", "215"]
every = 1.5
[[effect]]
do = "candle"
at = [[13, -1], [28, -1]]
chars = "▲▴"
colors = ["208", "214", "220"]
[[item]]
key = "G"
do = "logoff"
+++
{>lamp.ans}

               {!key}G{!}  goodbye
```

- Первый `twinkle` — свет под абажуром: прямоугольник арта, строки 5–7.
  Его звёзды — клетки `░` и `▒`. Примерно каждую секунду меняется пятая часть из них.
- Второй `twinkle` даёт четыре звезды на тёмном фоне арта, кремовые и оранжевые.
- `candle` даёт два огонька на последней строке страницы, рядом с клавишей `G`, оранжевые и жёлтые.
  Здесь подходят координаты страницы: экран шириной 40 столбцов, поэтому его строки не переносятся.

## Результат

- `velourbbs check` ничего не выводит.
- `velourbbs preview main` выводит экран из задачи 9: preview показывает экран
  до эффектов.
- `velourbbs preview main --keys +1s` показывает экран через секунду: звёзды и огоньки.
  `+1s,+1s` показывает его через одну и через две секунды.
  Случайные значения preview одинаковы при каждом запуске.
- Запусти `velourbbs serve`. PuTTY показывает мерцающий свет, звёзды и огоньки.
