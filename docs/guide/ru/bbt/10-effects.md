# Задача 10. Эффекты

«Эффект» меняет клетки экрана, пока экран ждёт клавишу.
В этой задаче ты добавляешь эффекты к лампе из задачи 9: свет лампы мерцает,
вокруг неё мигают звёзды, в темноте появляются и гаснут искры, рядом с клавишей
горят два маленьких огонька, на абажуре вспыхивают блики, а по лампе один раз
пробегает светлая полоса.
Используй каталог `myart` из задачи 9.

## Таблица `[[effect]]`

Каждый эффект — это одна таблица `[[effect]]` во front matter:

```
[[effect]]
do = "twinkle"
at = [37, 3]
chars = "*+·"
```

- `do` называет эффект: `twinkle`, `sparkle`, `candle`, `glint`, `sweep` или `lightning`.
- `at` — это «место»: клетки, где действует эффект (ниже).
- У экрана не больше 16 эффектов. Эффекты действуют в порядке файла:
  эффект меняет клетки после эффектов выше него.
- Экраны `goodbye` и `shutdown` не ждут клавишу, поэтому эффектов у них быть не может.
- Эффекты не действуют на странице со строкой More и пока пользователь вводит строку (задача 8).
- Каждый раз, когда BBS показывает экран, эффекты начинаются заново.

Полные правила: [live-screen](../../../specs/live-screen.md), разделы 5 и 6.1.

## Место

У `at` одна из трёх форм:

| Форма | Пример | Клетки |
|---|---|---|
| Точка `[col, row]` | `[61, 3]` | Одна клетка. |
| Прямоугольник `[col, row, width, height]` | `[1, 1, 80, 6]` | Прямоугольник от точки: `width` столбцов вправо и `height` строк вниз. |
| Массив точек | `[[61, 3], [70, 5]]` | Каждая точка — отдельное место со своим временем. |

- С `in = "<name>.ans"` координаты считаются в арте: столбец 1 и строка 1 —
  первая клетка арта. Место движется вместе с артом. Если текст над артом переносится
  на большее число строк, эффект остаётся на тех же клетках арта.
- С `in = "_<name>"` координаты считаются в строках фрагмента `{>_<name>}`:
  столбец 1 — левый край экрана, строка 1 — первая строка фрагмента.
  Место движется вместе с фрагментом и остаётся в его строках. Пример: с `in = "_logo"`
  `sweep` пробегает по логотипу из текста в цветах темы.
- Без `in` координаты считаются на странице. Столбец 1 — левый край экрана,
  строка 1 — первая строка страницы. Текст с переносом сдвигает строки под ним, поэтому
  используй эту форму только для строк без переноса: заголовка, угла или строки клавиш.
- Отрицательная координата считается с конца: `-1` — последний столбец или последняя строка
  арта, фрагмента либо экрана и страницы. Пример: `[-1, -1]` — клетка в правом нижнем углу.
- Живое поле (задача 5) и широкий символ, например `語`, не входят в место.
  Эффект никогда их не меняет.
- Клетка, которую экран не показывает, не входит в место: например,
  клетка арта, обрезанная у края узкого терминала.

`velourbbs check` выводит ошибку, если экран не вставляет арт из `in`
или не включает его фрагмент, или если клетка места лежит вне арта.

Полные правила: [live-screen](../../../specs/live-screen.md), раздел 6.2.

## Время

| Ключ | По умолчанию | Значение |
|---|---|---|
| `delay` | `0` | Секунды до начала отсчёта: 0–3600. |
| `delay_spread` | `0` | Случайная часть `delay`: задержка равна `delay` плюс-минус до `delay_spread`. |
| `every` | Своё у каждого эффекта. | Секунды между двумя сменами: 0.05–3600. |
| `spread` | Половина `every`. | Случайная часть `every`: каждый промежуток равен `every` плюс-минус до `spread`. |
| `times` | Нет: без конца. | Число смен: 1–10000. Потом эффект останавливается. |

- Значение — число секунд, например `0.5`.
- Первая смена приходит через `delay` секунд после показа. При `delay = 0` она приходит сразу при показе.
  Пример: `delay = 1` и `every = 1` при `spread = 0` дают смены через 1, 2 и 3 секунды.
- Чтобы первая смена ждала один промежуток, задайте `delay = every` и `delay_spread = spread`.
- С `spread = 0` каждая смена приходит ровно через `every` секунд после предыдущей.
- `every - spread` должно быть не меньше 0.05. `delay - delay_spread` должно быть не меньше 0.
- Каждая точка массива точек берёт свою случайную задержку. Пример: `delay = 2`
  и `delay_spread = 1` запускают каждую точку через 1–3 секунды.
- Пример: `times = 3` даёт три смены. После них эффект больше ничего не меняет:
  `twinkle` и `candle` сохраняют последнюю смену, события других эффектов заканчиваются как обычно.
- Смены случайны. У каждой сессии свои случайные значения.

Полные правила: [live-screen](../../../specs/live-screen.md), раздел 6.3.

## Эффект `twinkle`

Звезда, которая видна всегда и меняет свой символ.

| Ключ | По умолчанию | Значение |
|---|---|---|
| `at` | Обязателен. | Точка, прямоугольник или массив точек. |
| `chars` | Обязателен. | 1–32 символа шириной в одну клетку, среди них не меньше 2 разных. |
| `colors` | Нет. | 1–16 цветов: стиль, например `"215"` или `"#ffcc00"`, или имя стиля темы. |
| `every` | `1` | |
| `share` | `0.1` | Доля звёзд прямоугольника, которые меняются за раз: больше 0, не больше 1. |

- Точка показывает звезду с самого начала: свой символ, если он есть в `chars`, иначе первый
  символ `chars`. При каждой смене звезда берёт другой символ из `chars`.
- В прямоугольнике звёзды — это клетки с символом из `chars`.
  При каждой смене доля `share` из них берёт другой символ из `chars`.
- С `colors` каждый новый символ берёт случайный цвет из `colors`.
  Иначе он сохраняет цвет клетки. Фон не меняется.

## Эффект `candle`

Огонёк, который дрожит.

| Ключ | По умолчанию | Значение |
|---|---|---|
| `at` | Обязателен. | Точка, прямоугольник или массив точек. |
| `chars` | Обязателен. | 1–32 символа шириной в одну клетку. |
| `colors` | Обязателен. | 1–16 цветов, как у `twinkle`. |
| `every` | `0.2` | |
| `share` | `0.3` | Доля клеток прямоугольника, которые меняются за раз. |

- С самого начала каждая клетка места показывает первый символ `chars`
  в первом цвете `colors`.
- При каждой смене точка берёт случайный символ из `chars` и случайный цвет из `colors`.
  В прямоугольнике так делает доля `share` клеток.

Полные правила: [live-screen](../../../specs/live-screen.md), разделы 6.4 и 6.6.

## Эффект `sparkle`

Звезда, которая появляется и гаснет.

| Ключ | По умолчанию | Значение |
|---|---|---|
| `at` | Нет: весь арт или вся страница. | Точка, прямоугольник или массив точек. |
| `chars` | Обязателен. | 1–32 символа шириной в одну клетку. |
| `colors` | Нет. | 1–16 цветов, как у `twinkle`. |
| `over` | `false` | `true`: звезда может закрыть любую клетку. |
| `count` | `1` | Звёзды прямоугольника за раз: 1–100. Не для точки. |
| `time` | `2` | Секунды, которые видна звезда: 0.05–60. |
| `every` | `1` | |

- Каждый раз точка показывает случайный символ из `chars` на `time` секунд.
  В прямоугольнике так делают `count` случайных клеток.
- С `over = false` звезда появляется только на пустой клетке: на пробеле.
  Поэтому арт и текст остаются. С `over = true` звезда может закрыть любую клетку места.
- Клетка со звездой не берёт вторую звезду того же эффекта.
- С `colors` каждая звезда берёт случайный цвет из `colors`. Иначе она сохраняет цвет клетки.
  Фон не меняется.

Полные правила: [live-screen](../../../specs/live-screen.md), раздел 6.5.

## Яркость

`glint` и `sweep` делают клетку яркой и сохраняют её символ.
Они сдвигают цвет символа к цвету `peak` и обратно.
Фон не меняется.

- `peak` со значением `"#ffffff"` даёт белый. `peak` со значением `"230"` даёт кремовый.
  Имя стиля темы даёт цвет этого стиля.
- Клетка в цвете `default` берёт цвет `normal`.
- На терминале с 16 цветами ступеней между цветами мало.
  На 256 цветах и на true colour переход плавный.

Полные правила: [live-screen](../../../specs/live-screen.md), раздел 6.3.

## Эффект `glint`

Клетка вспыхивает и гаснет.

| Ключ | По умолчанию | Значение |
|---|---|---|
| `at` | Нет: весь арт или вся страница. | Точка, прямоугольник или массив точек. |
| `peak` | `#ffffff` | Цвет самого яркого момента: стиль или имя стиля темы. |
| `time` | `0.6` | Секунды от самого яркого момента до конца: 0.05–10. |
| `every` | `3` | |

- Каждый раз одна случайная клетка места становится яркой. Она гаснет за `time` секунд.
- Пробел не вспыхивает. Вспыхнуть может только клетка с символом.
- Точка вспыхивает всегда в одной и той же клетке.

## Эффект `sweep`

Светлое пятно бежит слева направо по символам места.

| Ключ | По умолчанию | Значение |
|---|---|---|
| `at` | Нет: весь арт или вся страница. | Прямоугольник. |
| `delay` | `0.5` | Секунды до начала отсчёта, как у других эффектов. |
| `every` | Нет: один прогон. | Секунды от начала прогона до начала следующего прогона. |
| `spread` | `0` | Только с `every`. |
| `times` | Нет: без конца. | Число прогонов. Только с `every`. |
| `peak` | `#ffffff` | Как у `glint`. |
| `time` | `0.6` | Секунды блика в конце каждой строки. |
| `width` | `3` | Половина ширины пятна в клетках: 1–20. |
| `speed` | `80` | Столбцы в секунду: 1–1000. |

- Пятно бежит по всем строкам места одновременно. Над несколькими строками
  это полоса.
- Пробел не становится ярким. Поэтому полоса показывает форму символов.
- Когда пятно доходит до последнего символа строки, этот символ вспыхивает на `time` секунд.
- Первый прогон приходит через `delay` секунд после показа, с `delay_spread`, как у других эффектов.
- Без `every` полоса пробегает один раз.
- С `every` следующие прогоны приходят через `every` секунд после начала предыдущего прогона.
  Без `times` прогоны идут без конца.
  Пример: `delay = 1`, `every = 5` и `times = 3` дают прогоны через 1, 6 и 11 секунд.

Полные правила: [live-screen](../../../specs/live-screen.md), разделы 6.7 и 6.8.

## Эффект `lightning`

Молния, которая вспыхивает на короткое время, один, два или три раза.

| Ключ | По умолчанию | Значение |
|---|---|---|
| `at` | Нет: весь арт или вся страница. | Прямоугольник. |
| `shape` | `both` | `slant`: молния из косых шагов. `square`: молния из линий и углов рамки. `both`: каждая молния случайно берёт одну из двух форм. |
| `chars` | `╲│╱` | 3 символа для `slant`: шаг вниз вправо, прямо вниз и вниз влево. У молнии `square` нет `chars`. |
| `peak` | `#ffffff` | Цвет молнии: стиль или имя стиля темы. |
| `over` | `false` | `true`: молния может закрыть любую клетку. |
| `time` | `0.3` | Секунды, которые видна последняя вспышка: 0.05–10. |
| `every` | `30` | |

- Каждая молния занимает случайную часть прямоугольника: от четверти его ширины и высоты до всего прямоугольника.
  Поэтому одна молния маленькая и в одном месте, а следующая широкая.
- Молния начинается в случайном столбце верхней строки своей части. Она идёт вниз
  до нижней половины части или дальше, со случайными шагами влево и вправо.
  Чем больше молния, тем больше у неё веток и тем они длиннее.
- Молния `square` идёт вниз горизонтальными отрезками и углами, как в старом BBS-арте:

  ```
     │
     └──┐
        └─┬───┐
          │   └─┐
         ┌┘     └┐
  ```

- Молния вспыхивает один, два или три раза. Каждая вспышка перед последней видна 0,1 секунды,
  потом пауза 0,1 секунды. Последняя вспышка видна `time` секунд.
- С `over = false` молния рисуется только на пустых клетках: арт и текст закрывают её.
  С `over = true` она закрывает любую клетку места.
- Молния сохраняет фон каждой клетки. У неё нет жирного и других атрибутов.
- Для символов ASCII напиши `chars = "\\|/"`: в TOML `\\` — это один `\`. Линии `square`
  есть в любом шрифте терминала.

Пример: молния в небе над текстом, примерно каждые 20 секунд, на странице шириной 80 столбцов:

```
[[effect]]
do = "lightning"
at = [1, 1, 80, 8]
every = 20
```

Полные правила: [live-screen](../../../specs/live-screen.md), раздел 6.9.

## Файл

Измени `screens/main.bbt`:

`examples/art/screens/main.bbt`:
```
+++
width = [40, 40]
fill = "spaces"
[[effect]]
do = "twinkle"
in = "lamp.ans"
at = [8, 5, 26, 3]
chars = "░▒"
share = 0.2
[[effect]]
do = "twinkle"
in = "lamp.ans"
at = [[4, 2], [37, 3], [2, 9], [39, 10]]
chars = "·+*"
colors = ["223", "215"]
every = 1.5
[[effect]]
do = "sparkle"
in = "lamp.ans"
chars = "·."
colors = ["137", "223"]
count = 2
time = 1.5
[[effect]]
do = "candle"
at = [[13, -1], [28, -1]]
chars = "▲▴"
colors = ["208", "214", "220"]
[[effect]]
do = "glint"
in = "lamp.ans"
at = [11, 2, 20, 3]
every = 2
[[effect]]
do = "sweep"
in = "lamp.ans"
[[item]]
key = "G"
do = "logoff"
+++
{>lamp.ans}

               {!key}G{!}  goodbye
```

- Первый `twinkle` — свет под абажуром: прямоугольник арта, строки 5–7.
  Его звёзды — клетки `░` и `▒`. Примерно каждую секунду меняется пятая часть из них.
- Второй `twinkle` даёт четыре звезды на тёмном фоне арта, кремовые и оранжевые.
- `sparkle` действует на весь арт. Примерно каждую секунду появляются две искры на 1,5 секунды.
  Они появляются только на пустых клетках, поэтому остаются на тёмном фоне и не закрывают лампу.
- `candle` даёт два огонька на последней строке страницы, рядом с клавишей `G`, оранжевые и жёлтые.
  Здесь подходят координаты страницы: экран шириной 40 столбцов, поэтому его строки не переносятся.
- `glint` действует на абажур: прямоугольник арта, строки 2–4.
  Примерно каждые 2 секунды одна клетка абажура вспыхивает белым и гаснет.
- `sweep` пробегает один раз по всей лампе, через полсекунды после показа.
  Он идёт последним, поэтому делает яркими и звёзды, и свет эффектов выше него.

## Результат

- `velourbbs check` ничего не выводит.
- `velourbbs preview main` выводит экран из задачи 9: preview показывает экран
  до эффектов.
- `velourbbs preview main --keys +1s` показывает экран через секунду: звёзды, искры, огоньки
  и последние блики `sweep` у правого края лампы.
  `+1s,+1s` показывает его через одну и через две секунды.
  Случайные значения preview одинаковы при каждом запуске.
- Запусти `velourbbs serve`. PuTTY показывает мерцающий свет, звёзды, искры, огоньки, блики
  и полосу.
