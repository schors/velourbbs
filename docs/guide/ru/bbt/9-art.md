# Задача 9. Арт

«ANSI-арт» — это картинка из символов и цветов.
В этой задаче ты показываешь арт на экране. Используй новый каталог BBS, например `myart`.
Файлы лежат в [`examples/art/`](../../../../examples/art/). Запиши каждый файл без `examples/art/`.
Тексты этого примера на английском.

1. Создай каталог `myart` и в нём каталог `screens`.
2. Скопируй файл `examples/art/screens/lamp.ans` из репозитория исходного кода
   в `myart/screens/lamp.ans`. Или попроси файл у сисопа.
   Руководство не показывает этот файл: в нём escape-последовательности.

## Вставка арта

```
{>lamp.ans}
```

- `{><name>.ans}` показывает арт `screens/<name>.ans`. В этой строке не должно быть другого текста.
- Каждая строка арта начинается у левого края экрана.
- Арт не меняет стиль текста после него.
- BBS обрезает арт шире экрана.
  `velourbbs check` предупреждает, когда арт шире наибольшей ширины экрана.

Полные правила: [bbt-format](../../../specs/bbt-format.md), разделы 3.4 и 6.2.

## Файлы

`examples/art/bbs.toml`:

```

Файл пустой: у BBS настройки по умолчанию.

`examples/art/screens/screens.toml`:
```
[theme.default]
normal = "223/235"
key    = "215 bold"
```

Стиль `key` задан номером 215 из 256 цветов. Оранжевый 215 остаётся тёплым и при 16 цветах: BBS заменяет его ближайшим номером 0–15.

`examples/art/screens/main.bbt`:
```
+++
width = [40, 40]
fill = "spaces"
[[item]]
key = "G"
do = "logoff"
+++
{>lamp.ans}

               {!key}G{!}  goodbye
```

- Арт шириной 40 столбцов. `width = [40, 40]` во front matter делает этот экран
  шириной 40 столбцов.
- Ключи `width`, `align`, `valign` и `fill` во front matter задают размещение одного экрана.
  В `[screen]` файла `screens/screens.toml` они задают размещение всех экранов.
- Здесь в `screens/screens.toml` нет `[screen]`. Поэтому у экрана `align = "center"` по умолчанию:
  на терминале шириной 80 столбцов BBS ставит экран по центру.

Экран:

```

- Фон тёмно-серый. Абажур лампы оранжевый с кремовым верхом.
  Свет под ним жёлтый и тёмно-оранжевый.
- Ножка серо-коричневая. Подставка коричневая.
- Слова «lit for» серо-коричневые. Значение поля, «xterm», кремовое.
  Клавиша `G` оранжевая и жирная, в стиле `key`.

## Положение экрана

```
+++
width = [40, 40]
align = "left"
valign = "middle"
+++
```

- `align` — положение на более широком терминале: `"left"`, `"center"` (по умолчанию) или `"right"`.
- `valign` — положение экрана, у которого строк меньше, чем у терминала:
  `"top"` (по умолчанию), `"middle"` или `"bottom"`.

Полные правила: [bbt-format](../../../specs/bbt-format.md), разделы 6.1 и 6.5.

## Поле в арте

Строка 12 файла `lamp.ans` содержит текст `lit for {term.type    }`.
BBS находит поле в арте и ставит значение на его место.

- Поле занимает клетки своего токена: здесь 15 клеток. BBS обрезает более длинное значение.
- Пробелы перед именем выравнивают значение вправо. Иначе значение выравнивается влево.
- У всех клеток токена должен быть один цвет фона.
  У всех его символов, кроме пробелов, должен быть один цвет текста.
  Иначе `velourbbs check` выводит ошибку (задача 10).
- Значение берёт цвета первого символа токена.
- В арте могут быть только поля: без токенов стиля, условий и подключений.
  Короткий алиас (задача 5) даёт короткое поле, например `{w}`.

Полные правила: [art-format](../../../specs/art-format.md), раздел 4.

## Цвета арта

Цвета 0–15 в арте — это цвета VGA: цвета редакторов арта.
Терминал может показывать цвета 0–15 с другими значениями. Например, Windows Terminal
показывает цвет 1 как `c50f1f`, а не как `aa0000` из VGA.

- При подключении BBS спрашивает у терминала его цвета 0–15.
- Когда они отличаются от VGA, BBS отправляет значения VGA из арта как цвета RGB.
  Терминалу на 256 цветов BBS отправляет ближайший номер 16–255.
- Терминалу на 16 цветов и терминалу без ответа BBS отправляет номера 0–15.
  Терминал показывает их своими цветами.
- Тема и токены стиля, например `{!14}`, всегда дают номера.
  Терминал показывает их своими цветами.

Полные правила: [telnet-term](../../../specs/telnet-term.md), раздел 7.3.

## Арт для малых терминалов

Экран может показывать другое содержимое на узком терминале. Пример с артом шириной 80 столбцов:

```
+++
width = [40, 80]
[[item]]
key = "G"
do = "logoff"
+++
{#if term.cols < 80}
{>_main_small}
{#else}
{>main.ans}
{/if}
```

На терминале меньше 80 столбцов экран показывает фрагмент `screens/_main_small.bbt`:
текст или арт меньшего размера.

Полные правила: [bbt-format](../../../specs/bbt-format.md), раздел 6.1.

## Новый арт

BBS читает арт только в «плоской форме». `velourbbs art import` переводит файл
редактора арта в плоскую форму.

1. Нарисуй арт в одном из этих редакторов. Сохрани его с настройками по умолчанию:
   - Moebius 1.0.29: Save (`.ans`);
   - icy_draw 0.6.2: Export в `.ans`;
   - PabloDraw 3.3.14-beta: Save as ANSI (`.ans`).
2. Храни этот «исходный файл» вне `screens/`, например в `art/logo.ans`.
3. Переведи его:

```
velourbbs art import art/logo.ans screens/logo.ans
```

4. Вставь арт строкой `{>logo.ans}`.

Moebius и PabloDraw не открывают плоскую форму. Чтобы изменить арт, правь исходный файл
и переведи его снова.

Полные правила: [art-import](../../../specs/art-import.md), разделы 2 и 3.

## Результат

- `velourbbs check` ничего не выводит.
- `velourbbs preview main` выводит экран, как выше, с полосой фона в 20 столбцов с каждой стороны.
- `velourbbs preview main --set term.type=ansi` выводит подпись `lit for ansi`.
- Останови сервер «Лампы». Запусти `velourbbs serve` в `myart`.
  PuTTY показывает лампу в центре окна.
