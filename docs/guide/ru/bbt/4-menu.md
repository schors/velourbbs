# Задача 4. Меню с горячими клавишами

## Пункты

Каждый `[[item]]` во front matter — один пункт меню:

```
[[item]]
key = "A"
do = "gosub about"
```

- `key` — клавиша: латинская буква, цифра или имя клавиши, например `ESC` или `ENTER`.
  Регистр не важен. Русская буква работает как латинская буква на той же клавише: `ф` — это `A`.
- `do` — действие: `gosub <screen>` открывает экран, `back` возвращает на экран,
  который его открыл, `logoff` завершает сеанс. Раздел «Стек навигации» описывает
  другие действия: `goto` и `top`.
- BBS не показывает пункты. Напиши текст пунктов и строку клавиш в теле.
  Строка клавиш показывает все клавиши экрана.

Полные правила: [bbt-format](../../../specs/bbt-format.md), раздел 8,
и [menu-nav](../../../specs/menu-nav.md), разделы 3–6.

## Экран `main`

В меню два пункта: `A` ведёт на экран `about`, `G` завершает сеанс.
Задача 5 добавляет пункт `T`, задача 7 — пункт `R`.

Запиши `screens/main.bbt` с таким текстом:

```
+++
[[item]]
key = "A"
do = "gosub about"
[[item]]
key = "G"
do = "logoff"
+++
{>_head}
       Добрый вечер. Здесь тихо и тепло.
       Садись поближе к свету.


         {!key}A{!}   О станции                               {!dim}кто мы{!}

         {!key}G{!}   До свидания                             {!dim}лампа подождёт{!}






       {!dim}Свет горит до утра.{!}

  {!line}────────────────────────────────────────────────────────────────────────────{!}

    {!key}A G{!}  {!dim}выбор{!}
```

Экран:

```text

  ────────────────────────────────────────────────────────────────────────────

       Лампа  ☼ BBS при свете лампы

       Добрый вечер. Здесь тихо и тепло.
       Садись поближе к свету.


         A   О станции                               кто мы

         G   До свидания                             лампа подождёт






       Свет горит до утра.

  ────────────────────────────────────────────────────────────────────────────

    A G  выбор
```

Клавиши оранжевые, в стиле `key`. Пояснения справа и слово «выбор» серо-коричневые, в стиле `dim`.

## Экран `about`

Клавиши `Esc` и `Enter` возвращают на экран, который открыл `about`:

```
[[item]]
key = "ESC"
do = "back"
```

`examples/lamp/ru/screens/about.bbt`:
```
+++
[[item]]
key = "ESC"
do = "back"
[[item]]
key = "ENTER"
do = "back"
+++
{>_head}
       «Лампа» — маленькая станция для друзей.
       Заходи, осмотрись, посиди немного.

       Станция работает на Velour BBS.
       Её экраны — простые текстовые файлы.










  {!line}────────────────────────────────────────────────────────────────────────────{!}

    {!key}Esc Enter{!}  {!dim}назад{!}
```

Экран:

```text

  ────────────────────────────────────────────────────────────────────────────

       Лампа  ☼ BBS при свете лампы

       «Лампа» — маленькая станция для друзей.
       Заходи, осмотрись, посиди немного.

       Станция работает на Velour BBS.
       Её экраны — простые текстовые файлы.










  ────────────────────────────────────────────────────────────────────────────

    Esc Enter  назад
```

Клавиши `Esc Enter` оранжевые, в стиле `key`. Слово «назад» серо-коричневое, в стиле `dim`.

## Стек навигации

BBS хранит открытые экраны сеанса в стеке. Каждое действие меняет стек:

| `do` | Действие |
|---|---|
| `gosub <screen>` | Открывает экран поверх текущего экрана. |
| `back` | Закрывает текущий экран и снова показывает экран под ним. На первом экране снова показывает тот же экран. |
| `top` | Закрывает все экраны над первым экраном и показывает первый экран. |
| `goto <screen>` | Показывает экран вместо текущего экрана. `back` потом ведёт на экран под ним. |

- Экран после `back` и `top` сохраняет свои аргументы (задача 7) и страницу текста.
- В стеке 16 экранов. `gosub` на 16-м экране удаляет второй экран.
  Первый экран остаётся.

Пример: `main` открывает `texts` через `gosub`, `texts` открывает `reader` через `gosub`.
В `reader` `back` показывает `texts`, а `top` показывает `main`.

Используй `gosub`, чтобы перейти на экран глубже, и `back`, чтобы вернуться. Тогда на экран
можно попасть разными путями, и ему не нужно знать предыдущий экран.

Полные правила: [menu-nav](../../../specs/menu-nav.md), раздел 4.1.

## Экран `goodbye`

После `logoff` BBS показывает экран `goodbye` и завершает сеанс.
У `goodbye` нет front matter и нет пунктов. У него нет строки клавиш.

```
       {!title}До встречи.{!}
       Лампа будет гореть для тебя.
```

`examples/lamp/ru/screens/goodbye.bbt`:
```
{>_head}
       {!title}До встречи.{!}
       Лампа будет гореть для тебя.













  {!line}────────────────────────────────────────────────────────────────────────────{!}
```

В экране 21 строка:

```text

  ────────────────────────────────────────────────────────────────────────────

       Лампа  ☼ BBS при свете лампы

       До встречи.
       Лампа будет гореть для тебя.













  ────────────────────────────────────────────────────────────────────────────
```

Слова «До встречи.» светло-персиковые и жирные, в стиле `title`.

## Экран `shutdown`

По SIGINT или SIGTERM `velourbbs serve` останавливается. Он показывает экран `shutdown`
каждому открытому сеансу и завершает сеанс. Скажи гостям, что BBS перезапускается:

```
       {!title}Лампа погаснет на минуту.{!}
       Заходи чуть позже.
```

Две строки:

```text
       Лампа погаснет на минуту.
       Заходи чуть позже.
```

Слова «Лампа погаснет на минуту.» светло-персиковые и жирные, в стиле `title`.

- Для `shutdown` действуют правила `goodbye`: нет пунктов и нет аргументов.
  Это не экран файла: у него нет ключа `file` (задача 7).
- BBS показывает только первую страницу `shutdown`. Она не ждёт клавишу.
- Без `screens/shutdown.bbt` BBS завершает сеансы без текста.
- Через 5 с BBS закрывает каждое соединение, которое ещё открыто.

`velourbbs preview shutdown` показывает экран.

Полные правила: [menu-nav](../../../specs/menu-nav.md), раздел 5.2,
и [telnet-term](../../../specs/telnet-term.md), раздел 10.2.

## Проверь клавиши

`velourbbs preview <screen> --keys <keys>` нажимает клавиши и показывает каждый экран.
Разделяй клавиши запятыми:

```
velourbbs preview main --keys A,ESC,G
```

В выводе перед каждым cell dump стоит строка события:

```
screen main
page 1 80x24 fill spaces
...
key A
screen about
page 1 80x24 fill spaces
...
key ESC
screen main
page 1 80x24 fill spaces
...
key G
logoff
screen goodbye
page 1 80x24 fill spaces
...
```

Полные правила: [menu-nav](../../../specs/menu-nav.md), раздел 7.

## Результат

- `velourbbs check` ничего не выводит.
- `velourbbs preview main --keys A,ESC,G` выводит строки событий, как выше.
- `velourbbs preview goodbye` выводит 21 строку, как выше.
- В telnet-клиенте `A` показывает `about`, `Esc` возвращает назад, `G` показывает `goodbye` и завершает сеанс.
