# Задача 4. Меню с горячими клавишами

## Пункты

Каждый `[[item]]` во front matter — один пункт меню:

```
[[item]]
key = "A"
do = "goto about"
```

- `key` — клавиша: латинская буква, цифра или имя клавиши, например `ESC` или `ENTER`.
  Регистр не важен. Русская буква работает как латинская буква на той же клавише: `ф` — это `A`.
- `do` — действие: `goto <screen>` показывает экран, `logoff` завершает сеанс.
- BBS не показывает пункты. Напиши текст пунктов и строку клавиш в теле.
  Строка клавиш показывает все клавиши экрана.

Полные правила: [bbt-format](../../../specs/bbt-format.md), раздел 8,
и [menu-nav](../../../specs/menu-nav.md), разделы 3–6.

## Экран `main`

В меню два пункта: `A` ведёт на экран `about`, `G` завершает сеанс.
Задача 5 добавляет пункт `T`, задача 7 — пункт `R`.

Запиши `screens/main.bbt` с таким текстом:

```
+++
[[item]]
key = "A"
do = "goto about"
[[item]]
key = "G"
do = "logoff"
+++
{>_head}
       Добрый вечер. Здесь тихо и тепло.
       Садись поближе к свету.


         {!key}A{!}   О станции                               {!dim}кто мы{!}

         {!key}G{!}   До свидания                             {!dim}лампа подождёт{!}






       {!dim}Свет горит до утра.{!}

  {!line}────────────────────────────────────────────────────────────────────────────{!}

    {!key}A G{!}  {!dim}выбор{!}
```

Экран:

```text

  ────────────────────────────────────────────────────────────────────────────

       Лампа  ☼ BBS при свете лампы

       Добрый вечер. Здесь тихо и тепло.
       Садись поближе к свету.


         A   О станции                               кто мы

         G   До свидания                             лампа подождёт






       Свет горит до утра.

  ────────────────────────────────────────────────────────────────────────────

    A G  выбор
```

Клавиши оранжевые, в стиле `key`. Пояснения справа и слово «выбор» серо-коричневые, в стиле `dim`.

## Экран `about`

Клавиши `Esc` и `Enter` возвращают на `main`:

```
[[item]]
key = "ESC"
do = "goto main"
```

`examples/lamp/ru/screens/about.bbt`:
```
+++
[[item]]
key = "ESC"
do = "goto main"
[[item]]
key = "ENTER"
do = "goto main"
+++
{>_head}
       «Лампа» — маленькая станция для друзей.
       Заходи, осмотрись, посиди немного.

       Станция работает на Velour BBS.
       Её экраны — простые текстовые файлы.










  {!line}────────────────────────────────────────────────────────────────────────────{!}

    {!key}Esc Enter{!}  {!dim}назад{!}
```

Экран:

```text

  ────────────────────────────────────────────────────────────────────────────

       Лампа  ☼ BBS при свете лампы

       «Лампа» — маленькая станция для друзей.
       Заходи, осмотрись, посиди немного.

       Станция работает на Velour BBS.
       Её экраны — простые текстовые файлы.










  ────────────────────────────────────────────────────────────────────────────

    Esc Enter  назад
```

Клавиши `Esc Enter` оранжевые, в стиле `key`. Слово «назад» серо-коричневое, в стиле `dim`.

## Экран `goodbye`

После `logoff` BBS показывает экран `goodbye` и завершает сеанс.
У `goodbye` нет front matter и нет пунктов. У него нет строки клавиш.

```
       {!title}До встречи.{!}
       Лампа будет гореть для тебя.
```

`examples/lamp/ru/screens/goodbye.bbt`:
```
{>_head}
       {!title}До встречи.{!}
       Лампа будет гореть для тебя.













  {!line}────────────────────────────────────────────────────────────────────────────{!}
```

В экране 21 строка:

```text

  ────────────────────────────────────────────────────────────────────────────

       Лампа  ☼ BBS при свете лампы

       До встречи.
       Лампа будет гореть для тебя.













  ────────────────────────────────────────────────────────────────────────────
```

Слова «До встречи.» светло-персиковые и жирные, в стиле `title`.

## Проверь клавиши

`velourbbs preview <screen> --keys <keys>` нажимает клавиши и показывает каждый экран.
Разделяй клавиши запятыми:

```
velourbbs preview main --keys A,ESC,G
```

В выводе перед каждым cell dump стоит строка события:

```
screen main
page 1 80x24 fill spaces
...
key A
screen about
page 1 80x24 fill spaces
...
key ESC
screen main
page 1 80x24 fill spaces
...
key G
logoff
screen goodbye
page 1 80x24 fill spaces
...
```

Полные правила: [menu-nav](../../../specs/menu-nav.md), раздел 7.

## Результат

- `velourbbs check` ничего не выводит.
- `velourbbs preview main --keys A,ESC,G` выводит строки событий, как выше.
- `velourbbs preview goodbye` выводит 21 строку, как выше.
- В telnet-клиенте `A` показывает `about`, `Esc` возвращает назад, `G` показывает `goodbye` и завершает сеанс.
