# Задача 6. Глубина цвета

## Глубина цвета терминала

Терминал показывает 16, 256 или 16777216 цветов: это его «глубина цвета».
При подключении BBS спрашивает терминал и читает тип терминала, который передаёт клиент.
Глубину даёт первая строка таблицы, которая подходит:

| Терминал | Глубина |
|---|---|
| Показывает цвет RGB, например Windows Terminal, iTerm2, Ghostty, xterm с direct colour | 16777216 |
| PuTTY или tmux | 16777216 |
| Тип кончается на `-direct`, или содержит `truecolor` или `24bit` | 16777216 |
| Тип содержит `256color` | 256 |
| Тип кончается на `-16color` или `-8color`, или равен `ansi`, `dumb`, `vt52`, `vt100`, `vt102`, `vt220`, `vt320`, `rxvt`, `xterm-color`, `eterm-color` или `cygwin` | 16 |
| Любой другой тип, например `xterm` | 256 |

- Клиент без типа получает `ansi`. Если его терминал не отвечает, он получает 16 цветов.
- Tera Term передаёт `xterm` и не показывает цвет RGB, то есть 256 цветов.

BBS заменяет каждый цвет ближайшим цветом этой глубины.
При 256 цветах кремовый текст `#e9dccb` становится нейтральным серым 253, и экран теряет тепло.
Поэтому подбирай цвета для каждой глубины вручную.
Номера 16–255 — это цвета палитры xterm на 256 цветов.
Номера 0–15 — это цвета VGA из [telnet-term](../../../specs/telnet-term.md), раздел 7.3.

Полные правила: [telnet-term](../../../specs/telnet-term.md), разделы 6 и 7.3.

## Темы глубины

```toml
[theme.256]
normal = "223/235"
title  = "230 bold"

[theme.16]
normal = "7/0"
title  = "15 bold"
```

- «Тема глубины» даёт другие стили для одной глубины.
  `[theme.256]` — для 256 цветов. `[theme.16]` — для 16 цветов.
- Стиль темы глубины заменяет стиль с тем же именем из `[theme.default]`.
  Остальные стили остаются.
- В теме глубины могут быть только `normal`, `more`, стили `md_*` (задача 7) и имена из `[theme.default]`.
- Для 16 цветов используй номера 0–15. Для 256 цветов используй номера 16–255.

Полные правила: [screens-toml](../../../specs/screens-toml.md), раздел 3.2.

## Ссылки на стили

```toml
[theme.default]
dim   = "#9e8a7c"
title = "#f7c7a3 bold"
more  = "dim"
md_h1 = "title underline"

[theme.16]
dim   = "8"
title = "15 bold"
```

- Стиль может назвать другой стиль. Это «ссылка». `more = "dim"` даёт `more` стиль `dim`.
- Ссылка может добавить атрибуты. `md_h1 = "title underline"` — это `title` с подчёркиванием.
- Ссылка берёт стиль своего имени в той же теме.
  При 16 цветах `more` — это `8`, а `md_h1` — `15 bold underline`.
  Поэтому пиши каждый цвет один раз в каждой таблице, а в других стилях называй его.
- Ссылка может назвать другую ссылку.
  Ссылка, которая ведёт обратно к своему стилю, — ошибка: «цикл».

Полные правила: [screens-toml](../../../specs/screens-toml.md), раздел 3.2.

## Строка More

Если у экрана больше строк, чем у терминала, BBS показывает его по страницам. Каждая страница, кроме последней,
кончается «строкой More». Пользователь нажимает любую клавишу и видит следующую страницу.
Пункты на строке More не работают.

```toml
[screen]
more = "    ещё ∙ любая клавиша"
```

`more` задаёт текст строки More. Без `more` текст — `-- More --`.
Стиль `more` задаёт её цвета.
С файлом `screens/screens.toml` ниже, для терминала в 12 строк, экран `about` занимает две страницы:

```
velourbbs preview about --size 80x12
```

```
page 1 80x12 fill spaces
...
|    ещё ∙ любая клавиша                                                         |
styles
...
page 2 80x12 fill spaces
...
```

Без строки-распорки в экране 14 строк. Поэтому строка-распорка не даёт строк.
Страница 1 содержит строки экрана 1–11 и строку More. Страница 2 содержит строки 12–14.

Полные правила: [bbt-format](../../../specs/bbt-format.md), раздел 6.4,
и [menu-nav](../../../specs/menu-nav.md), раздел 5.

## Файл `screens.toml`

Перепиши `screens/screens.toml` с таким текстом:

`examples/lamp/ru/screens/screens.toml`:
```
[screen]
width = [80, 80]
more = "    ещё ∙ любая клавиша"
fill = "spaces"

[theme.default]
normal = "#e9dccb/#2a201d"
dim    = "#9e8a7c"
line   = "#8a6a5c"
title  = "#f7c7a3 bold"
key    = "#ffb088 bold"
orn    = "#f2a27e"
more   = "dim"
md_h1     = "title"
md_h2     = "#f2a27e"
md_h3     = "#d9b99b"
md_strong = "title"
md_em     = "#d9b99b"
md_code   = "#c8b88a"
md_link   = "#d9b99b underline"
md_mark   = "orn"
md_frame  = "line"
md_dim    = "dim"

[theme.256]
normal = "223/235"
dim    = "137"
line   = "95"
title  = "230 bold"
key    = "216 bold"
orn    = "216"
md_h2     = "216"
md_h3     = "180"
md_em     = "180"
md_code   = "144"
md_link   = "180 underline"

[theme.16]
normal = "7/0"
dim    = "8"
line   = "8"
title  = "15 bold"
key    = "15 bold"
orn    = "7"
md_h2     = "15"
md_h3     = "15"
md_em     = "7"
md_code   = "15"
md_link   = "15 underline"
```

- При 256 цветах фон тёмно-серый (235), текст кремовый (223), а не серый (253).
- При 16 цветах экран серый: чёрный фон, светло-серый текст,
  тёмно-серые `dim` и `line`, белые `title` и `key`.
- Стили `md_*` — стили текстов. Их использует задача 7.
- `more`, `md_h1`, `md_strong`, `md_mark`, `md_frame` и `md_dim` — ссылки.
  На каждой глубине они берут стили `dim`, `title`, `orn` и `line` этой глубины.

## Посмотри на каждую глубину

`velourbbs preview` использует тип `xterm`, то есть 256 цветов. Другую глубину задай через `--set`:

```
velourbbs preview main --set term.colors=16
velourbbs preview main --set term.type=vt100
```

Обе команды показывают экран со стилями `[theme.16]`.
В cell dump цвета темы такие, как ты их написал.
Добавь `--view`, чтобы увидеть цвета глубины в своём терминале:

```
velourbbs preview main --view
velourbbs preview main --view --set term.colors=16
```

`--view` даёт ближайшие цвета глубины, как их получает telnet-клиент.
При 256 и 16777216 цветах арт выглядит одинаково в любом терминале.
При 16 цветах терминал показывает индексы 0–15 в своей палитре.

## Светлая тема

У некоторых терминалов светлый фон. Тёмный фон экрана на светлом терминале выглядит плохо.
«Светлая тема» даёт для таких терминалов другие стили.

```toml
[screen]
theme = "auto"

[theme.light.default]
normal = "#3a2a24/#f4ece0"
title  = "#8a3a1c bold"

[theme.light.16]
normal = "0/15"
title  = "4 bold"
```

- `[screen] theme` выбирает тему в начале сессии: `dark`, `light` или `auto`.
  Без `theme` сессия использует тёмную тему.
- С `auto` тему выбирает поле `term.background` (задача 5).
  `light` даёт светлую тему. Терминал без ответа получает тёмную тему.
- «Светлые таблицы» `[theme.light.default]`, `[theme.light.16]` и `[theme.light.256]`
  дают другие стили в светлой теме.
- Светлая тема глубины — это тема этой глубины со стилями `[theme.light.default]`,
  а затем со стилями светлой таблицы этой глубины.
- Каждое имя светлой таблицы должно быть именем темы, как в теме глубины.
- В светлой теме `normal` берёт недостающий цвет из `0/15`: чёрный текст на белом фоне.

Lamp остаётся с тёмной темой. Чтобы попробовать светлую тему, добавь ключ `theme` в таблицу `[screen]`
файла `screens/screens.toml`, а светлые таблицы — в конец файла.
Потом задай фон терминала:

```
velourbbs preview main --set term.background=light
velourbbs preview main --set term.background=light --set term.colors=16
```

Первая команда показывает стили `[theme.light.default]`.
Вторая команда показывает ещё и стили `[theme.light.16]`.

### Тема пользователя

Пункты с действием `theme` дают пользователю выбрать тему.
Чтобы попробовать их, добавь эти пункты во front matter `screens/main.bbt`,
а строку клавиш — в его текст:

```toml
[[item]]
key = "L"
do = "theme light"
[[item]]
key = "D"
do = "theme dark"
[[item]]
key = "B"
do = "theme auto"
```

```
[L] светлая  [D] тёмная  [B] по терминалу: {session.theme}
```

- `theme light` и `theme dark` выбирают тему. `theme auto` возвращает выбор полю `term.background`.
- BBS снова показывает текущий экран с новой темой. В файловом экране она показывает ту же страницу.
- Выбор действует до конца сессии.
- Поле `session.theme` даёт выбор: `dark`, `light` или `auto`.
  В начале сессии это `[screen] theme`.

Запусти пункты через `--keys`. `--set session.theme` задаёт выбор в начале:

```
velourbbs preview main --keys D,L,B --set term.background=light
velourbbs preview main --set session.theme=light
```

Первая команда показывает `main` с тёмной темой после `D` и со светлой темой после `L`.
После `B` она снова показывает светлую тему, потому что `term.background` равно `light`.

Полные правила: [screens-toml](../../../specs/screens-toml.md), разделы 3.1 и 3.2,
и [menu-nav](../../../specs/menu-nav.md), раздел 4.

## Результат

- `velourbbs check` ничего не выводит.
- `velourbbs preview main` выводит строку 4 со стилями `[theme.256]`:

```
4: 1-7 223/235, 8-12 230/235 bold, 13-14 223/235, 15-16 216/235, 17-35 137/235, 36-80 223/235
```

- `velourbbs preview main --set term.colors=16` выводит строку 4 со стилями `[theme.16]`:

```
4: 1-7 7/0, 8-12 15/0 bold, 13-16 7/0, 17-35 8/0, 36-80 7/0
```

- PuTTY показывает тёмно-серый фон и кремовый, а не серый текст.
  В PuTTY установи Connection > Data > «Terminal-type string» в `vt100` и подключись снова:
  PuTTY показывает серый экран в 16 цветах.
  Потом верни в «Terminal-type string» значение `xterm`.
