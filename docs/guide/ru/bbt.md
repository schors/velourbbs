# Руководство по BBT

Это руководство учит писать экраны Velour BBS.
Оно для художника и автора экранов.
Нужны текстовый редактор, терминал и telnet-клиент.

## Введение

### Каталог BBS

«Каталог BBS» содержит файлы одной BBS:

| Файл | Содержимое |
|---|---|
| `bbs.toml` | Настройки хоста. В этом руководстве файл пустой. |
| `screens/screens.toml` | Настройки экранов: ширина, стили и другие значения. |
| `screens/<name>.bbt` | «Экран»: текстовый файл. BBS показывает его пользователю. |
| `screens/_<name>.bbt` | «Фрагмент»: часть экрана. Его имя начинается с `_`. |

Запускай каждую команду `velourbbs` в каталоге BBS.

### Программа `velourbbs`

Собери программу с помощью Go. В репозитории исходного кода Velour BBS выполни:

```
go build ./cmd/velourbbs
```

Команда создаёт файл `velourbbs` (`velourbbs.exe` в Windows).
Положи его в каталог из `PATH`. Или попроси программу у сисопа.

### Пример

Задачи строят пример BBS «Лампа». Его файлы лежат в
[`examples/lamp/ru/`](../../../examples/lamp/ru/).

- Строка с путём и двоеточием показывает целый файл примера.
  Пример: `` `examples/lamp/ru/screens/main.bbt`: ``.
  Запиши этот файл в свой каталог BBS без `examples/lamp/ru/`: `screens/main.bbt`.
- Остальные блоки показывают часть файла, команду или вывод.

Каждая задача ссылается на спецификации с полными правилами.

## Задача 1. Каталог BBS

1. Создай каталог, например `mybbs`. Создай в нём каталог `screens`.
2. Создай пустой файл `bbs.toml`.
3. Создай `screens/main.bbt` с таким текстом:

```
+++
[[item]]
key = "G"
do = "logoff"
+++
Привет! Это моя BBS.

G  до свидания
```

Строки между двумя строками `+++` — это «front matter». Он задаёт меню экрана.
Здесь в меню один пункт: клавиша `G` завершает сеанс (`logoff`).
У экрана должен быть хотя бы один пункт. Только у экрана `goodbye` нет пунктов (задача 4).
Остальные строки — это «тело»: текст экрана.
BBS показывает экран `main` первым.

### Проверь файлы

Выполни:

```
velourbbs check
```

Если файлы верны, команда ничего не выводит.
Иначе она выводит по строке на каждую ошибку или предупреждение:

```
screens/_x.bbt:1:1: warning: no screen uses this file
screens/main.bbt:2:1: item "G": do: unknown action "logof"
```

Строка содержит файл, номер строки, номер столбца и сообщение.
Ошибка в пункте указывает строку 2: первую строку front matter.
У предупреждения перед сообщением стоит `warning:`. Предупреждение не останавливает BBS. Ошибка останавливает.
Полные правила: [screen-render](../../specs/screen-render.md), раздел 3.1.

### Посмотри на экран

Выполни:

```
velourbbs preview main
```

Команда выводит «cell dump» экрана для терминала 80 столбцов на 24 строки:

```
page 1 80x24 fill none
|Привет! Это моя BBS.                                                            |
|                                                                                |
|G  до свидания                                                                  |
styles
1: 1-80 7/0
2: 1-80 7/0
3: 1-80 7/0
```

- Первая строка содержит страницу, размер терминала и заполнение строк под экраном.
- Каждая строка экрана стоит между двумя `|`.
- Каждая строка после `styles` содержит номер строки и «отрезки стилей» этой строки.
  Отрезок содержит первый столбец, последний столбец и стиль. `7/0` — светло-серый на чёрном.

Для других размеров используй `--size`, например `velourbbs preview main --size 132x43`.
Полные правила: [screen-render](../../specs/screen-render.md), разделы 3.2 и 3.3.

### Посмотри на экран в telnet-клиенте

1. Выполни `velourbbs serve`. Сервер слушает порт 2323.
2. Подключи telnet-клиент к `localhost`, порт 2323. Используй PuTTY или Tera Term:
   они показывают UTF-8 и 256 цветов. SyncTERM и NetRunner не показывают UTF-8.
   В PuTTY выбери тип соединения «Telnet».
   Установи «Close window on exit» в «Never»: иначе PuTTY закрывает окно в конце сеанса.
3. Нажми `G`, чтобы завершить сеанс.

Сервер читает файлы только при запуске. После каждого изменения файла
останови сервер клавишами Ctrl+C и запусти снова.
Полные правила: [telnet-term](../../specs/telnet-term.md), разделы 3 и 6.

### Результат

- `velourbbs check` ничего не выводит.
- Telnet-клиент показывает две строки текста. `G` завершает сеанс.

## Задача 2. Первый экран

В этой задаче ты пишешь первый экран «Лампы». Меню остаётся прежним: один пункт `G`. Задача 4 добавляет остальные пункты.

### Ширина и стили

Создай `screens/screens.toml` с таким текстом:

```toml
[screen]
width = [80, 80]
fill = "spaces"

[theme.default]
normal = "#e9dccb/#2a201d"
dim    = "#9e8a7c"
line   = "#8a6a5c"
title  = "#f7c7a3 bold"
key    = "#ffb088 bold"
orn    = "#f2a27e"
```

- `width = [80, 80]` задаёт наименьшую и наибольшую ширину экрана.
  Поэтому экран всегда шириной 80 столбцов. На более широком терминале BBS ставит его по центру.
  На более узком терминале она обрезает строки.
- `fill = "spaces"` заполняет строки терминала под экраном стилем `normal`.
- `[theme.default]` — это «тема»: она даёт имя каждому стилю.
  Стиль — это цвет текста, цвет фона после `/` и атрибуты, например `bold`.
  Цвет — это `#rrggbb` или число от 0 до 255.
- `normal` — стиль фона экрана и обычного текста.
  Стиль без цвета фона берёт фон из `normal`.

Полные правила: [screens-toml](../../specs/screens-toml.md), разделы 3.1 и 3.2,
и [bbt-format](../../specs/bbt-format.md), разделы 6.1–6.3, 6.5 и 7.

### Текст и токены стиля

- Каждая строка тела — одна строка экрана. Пустая строка тела — пустая строка экрана.
  Строка шире экрана переносится по пробелу на несколько строк экрана.
- Пробелы в начале строки сохраняются.
- `{!name}` включает стиль `name` из темы. `{!}` снова включает стиль `normal`.
  Стиль действует и на следующих строках, до следующего токена стиля.

Пример:

```
       {!title}Лампа{!}  {!orn}☼ {!dim}BBS при свете лампы{!}
```

Эта строка показывает слово «Лампа» светло-персиковым жирным, в стиле `title`,
солнце `☼` тёплым оранжевым, в стиле `orn`, и подзаголовок серо-коричневым, в стиле `dim`.

### Экран

Перепиши `screens/main.bbt` с таким текстом:

```
+++
[[item]]
key = "G"
do = "logoff"
+++

  {!line}────────────────────────────────────────────────────────────────────────────{!}

       {!title}Лампа{!}  {!orn}☼ {!dim}BBS при свете лампы{!}

       Добрый вечер. Здесь тихо и тепло.
       Садись поближе к свету.











       {!dim}Свет горит до утра.{!}

  {!line}────────────────────────────────────────────────────────────────────────────{!}

    {!key}G{!}  {!dim}до свидания{!}
```

В экране 23 строки:

```text

  ────────────────────────────────────────────────────────────────────────────

       Лампа  ☼ BBS при свете лампы

       Добрый вечер. Здесь тихо и тепло.
       Садись поближе к свету.











       Свет горит до утра.

  ────────────────────────────────────────────────────────────────────────────

    G  до свидания
```

- Фон тёмно-коричневый. Текст кремовый.
- Две линии коричневые, в стиле `line`. Они занимают столбцы 3–78.
- Заключительная строка «Свет горит до утра.» и слова «до свидания» серо-коричневые, в стиле `dim`.
- Клавиша `G` оранжевая и жирная, в стиле `key`.

PuTTY и Tera Term показывают 256 цветов. Там фон тёмно-серый.
Задача 6 задаёт стили для 256 цветов.

### Результат

- `velourbbs check` ничего не выводит.
- `velourbbs preview main` выводит 23 строки. У строк 2 и 4 такие отрезки стилей:

```
2: 1-2 #e9dccb/#2a201d, 3-78 #8a6a5c/#2a201d, 79-80 #e9dccb/#2a201d
4: 1-7 #e9dccb/#2a201d, 8-12 #f7c7a3/#2a201d bold, 13-14 #e9dccb/#2a201d, 15-16 #f2a27e/#2a201d, 17-35 #9e8a7c/#2a201d, 36-80 #e9dccb/#2a201d
```

- Telnet-клиент показывает экран с тёмным фоном на всех строках.

Сохрани вывод для задачи 3:

```
velourbbs preview main > task2.txt
```

## Задача 3. Шапка

Каждый экран «Лампы» начинается с одних и тех же 5 строк: это «шапка».
Напиши их один раз во фрагменте и подключи фрагмент в каждом экране.

- Фрагмент — это `screens/_<name>.bbt`. У него нет front matter.
- Строка `{>_<name>}` подключает фрагмент: BBS ставит строки фрагмента на её место.
  В этой строке не должно быть другого текста.
- После подключения действует тот же стиль, что и до него.

Полные правила: [bbt-format](../../specs/bbt-format.md), разделы 3.3 и 3.4.

В `screens/main.bbt` замени строки 1–5 одной строкой:

```
+++
[[item]]
key = "G"
do = "logoff"
+++
{>_head}
       Добрый вечер. Здесь тихо и тепло.
```

Перенеси эти 5 строк во фрагмент:

`examples/lamp/ru/screens/_head.bbt`:
```

  {!line}────────────────────────────────────────────────────────────────────────────{!}

       {!title}Лампа{!}  {!orn}☼ {!dim}BBS при свете лампы{!}

```

### Результат

- `velourbbs check` ничего не выводит.
- `velourbbs preview main` выводит то же, что и в задаче 2. Для сравнения выполни:

```
velourbbs preview main > task3.txt
diff task2.txt task3.txt
```

`diff` ничего не выводит. В Windows используй `fc task2.txt task3.txt`.

## Задача 4. Меню с горячими клавишами

### Пункты

Каждый `[[item]]` во front matter — один пункт меню:

```
[[item]]
key = "A"
do = "goto about"
```

- `key` — клавиша: латинская буква, цифра или имя клавиши, например `ESC` или `ENTER`.
  Регистр не важен. Русская буква работает как латинская буква на той же клавише: `ф` — это `A`.
- `do` — действие: `goto <screen>` показывает экран, `logoff` завершает сеанс.
- BBS не показывает пункты. Напиши текст пунктов и строку клавиш в теле.
  Строка клавиш показывает все клавиши экрана.

Полные правила: [bbt-format](../../specs/bbt-format.md), раздел 8,
и [menu-nav](../../specs/menu-nav.md), разделы 3–6.

### Экран `main`

В меню три пункта: `A` ведёт на экран `about`, `T` — на экран `term`,
`G` завершает сеанс.

`examples/lamp/ru/screens/main.bbt`:
```
+++
[[item]]
key = "A"
do = "goto about"
[[item]]
key = "T"
do = "goto term"
[[item]]
key = "G"
do = "logoff"
+++
{>_head}
       Добрый вечер. Здесь тихо и тепло.
       Садись поближе к свету.


         {!key}A{!}   О станции                               {!dim}кто мы{!}

         {!key}T{!}   Твой терминал                           {!dim}размер и цвета{!}

         {!key}G{!}   До свидания                             {!dim}лампа подождёт{!}




       {!dim}Свет горит до утра.{!}

  {!line}────────────────────────────────────────────────────────────────────────────{!}

    {!key}A T G{!}  {!dim}выбор{!}
```

Экран:

```text

  ────────────────────────────────────────────────────────────────────────────

       Лампа  ☼ BBS при свете лампы

       Добрый вечер. Здесь тихо и тепло.
       Садись поближе к свету.


         A   О станции                               кто мы

         T   Твой терминал                           размер и цвета

         G   До свидания                             лампа подождёт




       Свет горит до утра.

  ────────────────────────────────────────────────────────────────────────────

    A T G  выбор
```

Клавиши оранжевые, в стиле `key`. Пояснения справа и слово «выбор» серо-коричневые, в стиле `dim`.

### Экран `about`

Клавиши `Esc` и `Enter` возвращают на `main`:

```
[[item]]
key = "ESC"
do = "goto main"
```

`examples/lamp/ru/screens/about.bbt`:
```
+++
[[item]]
key = "ESC"
do = "goto main"
[[item]]
key = "ENTER"
do = "goto main"
+++
{>_head}
       «Лампа» — маленькая станция для друзей.
       Заходи, осмотрись, посиди немного.

       Станция работает на Velour BBS.
       Её экраны — простые текстовые файлы.










  {!line}────────────────────────────────────────────────────────────────────────────{!}

    {!key}Esc Enter{!}  {!dim}назад{!}
```

Экран:

```text

  ────────────────────────────────────────────────────────────────────────────

       Лампа  ☼ BBS при свете лампы

       «Лампа» — маленькая станция для друзей.
       Заходи, осмотрись, посиди немного.

       Станция работает на Velour BBS.
       Её экраны — простые текстовые файлы.










  ────────────────────────────────────────────────────────────────────────────

    Esc Enter  назад
```

Клавиши `Esc Enter` оранжевые, в стиле `key`. Слово «назад» серо-коричневое, в стиле `dim`.

Экран `term` появится в задаче 5. До тех пор скопируй `screens/about.bbt` в `screens/term.bbt`.
Иначе `velourbbs check` выводит ошибку `item "T": do: unknown screen "term"`.

### Экран `goodbye`

После `logoff` BBS показывает экран `goodbye` и завершает сеанс.
У `goodbye` нет front matter и нет пунктов. У него нет строки клавиш.

```
       {!title}До встречи.{!}
       Лампа будет гореть для тебя.
```

`examples/lamp/ru/screens/goodbye.bbt`:
```
{>_head}
       {!title}До встречи.{!}
       Лампа будет гореть для тебя.













  {!line}────────────────────────────────────────────────────────────────────────────{!}
```

В экране 21 строка:

```text

  ────────────────────────────────────────────────────────────────────────────

       Лампа  ☼ BBS при свете лампы

       До встречи.
       Лампа будет гореть для тебя.













  ────────────────────────────────────────────────────────────────────────────
```

Слова «До встречи.» светло-персиковые и жирные, в стиле `title`.

### Проверь клавиши

`velourbbs preview <screen> --keys <keys>` нажимает клавиши и показывает каждый экран.
Разделяй клавиши запятыми:

```
velourbbs preview main --keys A,ESC,G
```

В выводе перед каждым cell dump стоит строка события:

```
screen main
page 1 80x24 fill spaces
...
key A
screen about
page 1 80x24 fill spaces
...
key ESC
screen main
page 1 80x24 fill spaces
...
key G
logoff
screen goodbye
page 1 80x24 fill spaces
...
```

Полные правила: [menu-nav](../../specs/menu-nav.md), раздел 7.

### Результат

- `velourbbs check` ничего не выводит.
- `velourbbs preview main --keys A,ESC,G` выводит строки событий, как выше.
- `velourbbs preview goodbye` выводит 21 строку, как выше.
- В telnet-клиенте `A` показывает `about`, `Esc` возвращает назад, `G` показывает `goodbye` и завершает сеанс.
