# Экраны

## Что делает

Экран - текстовый файл BBT, который пишет СисОп. Velour собирает из него страницу
под терминал гостя при каждом показе: ширину, высоту, цвета и язык.

## Как

### Файл

Файл BBT - это UTF-8. Вверху между строками `+++` стоят настройки в TOML 1.1
([TOML](https://toml.io/en/v1.1.0)): ширина, пункты меню, эффекты.
Ниже идёт текст с токенами:

- `{term.cols}` - поле, `{term.type      }` - поле фиксированной ширины;
- `{!gold}` - стиль по имени из темы;
- `{#if term.cols >= 100}`, `{#else}`, `{/if}` - условие;
- `{>_foot}` - вставка фрагмента, `{>logo.ans}` - вставка арта;
- `{~}`, `{~.}`, `{~─}` - растяжка.

### Ширина и высота

Экран задаёт диапазон ширины. У этой станции `width = [68, 108]`, `align = "center"`
и `gutter = 6`: колонка текста - 64 клетки при 80 колонках и 104 при 132.
Растяжки делят свободные клетки строки: `{~.}` рисует отточие, `{~─}` - линию.
Строка `{~}` делит свободные строки экрана. Так строка клавиш стоит внизу
и при 24, и при 43 строках.

### Условия

В грамматике условий 7 правил: `or`, `and`, `not` и сравнения `==`, `!=`, `<`, `<=`, `>`, `>=`.
Числа сравниваются любым оператором, строки - только `==` и `!=`.
Скобок и арифметики нет. Типы полей известны заранее, поэтому `velourbbs check`
находит ошибку типа до запуска.

### Тема

`screens.toml` переводит имена ролей брендбука в стили. Таблицы `[theme.16]` и `[theme.256]`
дают другие цвета для 16 и 256 цветов, `[theme.light]` - для светлого фона.
С `theme = "auto"` Velour выбирает светлую тему по цвету фона из опроса терминала.

### Живой экран

Экран живёт, пока ждёт клавишу, и скрипт для этого не нужен.

- Живое поле, например `{bbs.time live}`, обновляется каждую секунду на своём месте.
  Так идут часы внизу разделов. На экране "О станции" так же меняются время на связи,
  число открытых сеансов и время работы станции.
- Эффектов шесть: `twinkle` (звёзды мерцают), `sparkle` (звёзды загораются и гаснут),
  `candle` (свеча дрожит), `glint` (буква вспыхивает), `sweep` (свет бежит по строке)
  и `lightning` (бьёт молния).
- Эта станция использует `sweep`: по логотипу на входе, по шапке с её линией
  и по линии над клавишами. Свет на шапке бежит примерно раз в 45 секунд.

### Три языка

Один каталог BBS держит русский, английский и литовский. Экраны языка лежат
в `screens/<язык>/`, тексты - в `content/<язык>/`. Файл без текста, например логотип,
один на все языки. Входной экран спрашивает язык и открывает меню на нём.
Тест проверяет, что у экранов всех языков одинаковые пункты.

### Проверка

`velourbbs check` читает все экраны до запуска. Ошибка приходит с файлом,
строкой и столбцом. Неизвестный ключ TOML - тоже ошибка с местом.

## Что получает

Одну страницу под конкретный терминал. Пример - экран "О станции":
он показывает размер, тип, имя программы, цвета, фон и ширину кириллицы,
которые Velour узнал при подключении.

## Ограничения

- Раскладка не меняется при `term.ambiguous` 2: столбцы съезжают, рамки и арт ломаются.
- Графема шириной 0 или длиннее 32 байт в файле - ошибка.
- Скриптов пока нет. Моды на Lua - в планах.
