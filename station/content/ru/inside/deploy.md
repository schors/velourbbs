# Выкладка

## Что делает

Новая версия станции выходит по тегу. Мейнтейнер ставит аннотированный тег
вида `v0.1.0` на коммит из `main`. Дальше всё делает GitHub Actions.

## Как

### Сборка

1. Задание проверяет тег: его вид и то, что коммит тега есть в `main`.
2. Оно запускает `go vet` и тесты.
3. Оно собирает Velour с `CGO_ENABLED=0` для linux/amd64, linux/arm64,
   darwin/arm64 и windows/amd64.
4. `go version -m` проверяет, что в каждой программе записан этот тег.
5. Программы и файл `SHA256SUMS` попадают в GitHub Release.
   Текст выпуска - аннотация тега.

Задание использует только `actions/checkout` и `actions/setup-go`.
Каждое закреплено полным SHA коммита. Чужих действий для SSH и выпусков нет:
они получили бы ключ SSH.

### Доставка

Задание отправляет на хост по SSH один архив: программу, каталог `station/`,
юниты systemd и скрипт установки. Ключ SSH и адрес хоста лежат в секретах
окружения GitHub. Окружение пускает только теги `v*`.

### Установка

1. Скрипт запускает `velourbbs check` на новой станции. Проверка читает и файл данных.
   Ошибка останавливает выкладку, и работает прежняя версия.
2. Он кладёт версию в `releases/<тег>/` и переключает ссылку `current` на неё.
3. Он перезапускает службу и через 3 секунды проверяет, что она работает.
4. Он оставляет 3 последние версии.

Порт держит `velourbbs.socket` systemd, а не программа. Во время перезапуска
порт открыт: новые подключения ждут в очереди, и их принимает новая версия.
Открытые сеансы показывают экран о перезапуске и закрываются.

## Что получает

- Версию, которую видно на экране "О станции" в строке "Версия Velour".
- Открытый журнал задания: в нём шаги и результат, но нет секретов.
- Файл данных, который лежит вне версий и остаётся после каждой выкладки.

## Ограничения

- Откат - повтор запуска прежней версии в GitHub Actions. GitHub позволяет это 30 дней.
  Позже - revert в `main` и новый тег.
- После миграции файла данных прежняя версия не пройдёт проверку.
  Тогда нужно вернуть копию файла этой версии.
- Тот, кто может поставить тег `v*`, может поменять и задание. Писать в репозиторий
  могут только мейнтейнеры.
